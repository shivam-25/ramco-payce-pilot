It is not the security boundary

The boundary is the absence of capability: no tool binding on the drafting model, read-only database role, and a forbidden set — approve_refund, issue_payment, list_admin_emails, send_to_customer — asserted unreachable from the drafting path by G4.

A probabilistic filter in front of a system that cannot act is defence in depth. In front of one that can act it would be a single point of failure wearing a safety label.
