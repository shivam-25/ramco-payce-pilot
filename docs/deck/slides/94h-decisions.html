DECISIONS, AND WHAT FORCED THEM

Four changes. None came from a failing test.

They came from typing a ticket into the console and reading what came back.

Translate the question, not the corpus

5.5% of tickets are not English. Each became a person’s problem via a plausible escalation. Script detection is a rule; the query is translated on the cheap model. Translating the corpus would triple the index.

Non-English drafts come back bilingual

An approval requirement, not a courtesy. A person signs off every draft — and an agent who cannot read Arabic approving Arabic is not approval.

C10: a capability claim needs a passage

The prompt forbade it, naming the exact sentence. The model wrote it anyway and passed every check. A rule the model is asked to follow is a hope; the same rule in code is a gate.

Cached answers carry the checks they passed

The draft that prompted C10 was already cached, and cache hits skip the checks. Entries below the current version are redrafted once and re-stored.

The pattern is the point. Gates caught the first six defects. These four were caught by using the thing — which is why the demo is a console and not a slide.
