THE CONSOLE, WHILE IT IS WORKING

Each box lights up as it closes. The desk never goes quiet.

A WebSocket carries the pipeline’s own events to the browser, so the wait is legible instead of a spinner. First stage 1.3s, first token 2.2s, complete 2.5s.

Per-box timings are measured, not decorative: classify 340ms is the only stage that costs anything. The gate, the lookup and the injection screen are <1ms — they are code, not a model.

Impact beside the queue: 1.1 h of agent time returned at 22.9 min a drafted reply — 26.9 measured from the cost sheet, less 4 to read and approve. The speed tile is honest about a cold run: 3 of 6 over the 3s gate, because this was the first batch after an idle period.
