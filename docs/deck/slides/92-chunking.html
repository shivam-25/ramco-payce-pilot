CHUNKING — FOUR STRATEGIES, MEASURED

The winner adds context, not size.

A_whole_doc

one chunk per document · hit@5 0.90, precision 0.18

B_fixed_512

512 tokens, blind to structure · hit@5 0.87 — the worst, and the most common default

C_heading

split on headings · hit@5 0.97, precision 0.41

D_heading_context

heading split, each chunk prefixed with its document, region and the dates it is in force · hit@5 0.97, precision 0.46, MRR 0.87

C and D retrieve the same documents. D ranks them better, and the difference is the prefix.

A chunk that says only “the ceiling is INR 15,000” is a fact with no owner. The same chunk prefixed with [Statutory rule for IN, in force from 2026-08-01] can be ranked, filtered and cited.

Fixed-size chunking loses most to the same cause: it cuts a rule away from the heading that says which country and which period it belongs to.
